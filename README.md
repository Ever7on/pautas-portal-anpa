# Pautas Portal ANPA 2026

Quadro de pautas da Assessoria de Comunicação da Associação Norte do Pará para o Portal de Notícias Adventistas, montado a partir do Calendário de Atividades 2026 “Legado que Ilumina”.

## O que tem

- Tabela por mês e visão kanban
- Status: A pautar, Pré-pauta, Em produção, Publicada e Não feita
- Prioridade, responsável, prazos calculados e link da matéria publicada
- Criação e edição de pautas
- Sugestões de pautas para os meses com poucos eventos

## Como abrir

Acesse pelo GitHub Pages: `https://ever7on.github.io/pautas-portal-anpa/`

Para instalar como aplicativo:
- **Android (Chrome):** menu ⋮ → *Instalar app* ou *Adicionar à tela inicial*
- **iPhone (Safari):** botão Compartilhar → *Adicionar à Tela de Início*
- **Computador (Chrome/Edge):** ícone de instalar na barra de endereço

## Onde os dados ficam salvos

As mudanças (status, prioridade, edições, novas pautas e links) ficam salvas **no navegador de cada aparelho**. Elas não aparecem para outras pessoas nem em outro aparelho.

Na primeira vez em cada aparelho, o quadro abre com os status e as pautas registrados até 16/11/2026.

O quadro também abre sem internet, com a última cópia salva no aparelho.
